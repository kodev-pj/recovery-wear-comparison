# リカバリーウェア比較

TENTIAL、VENEX、ReDの代表的なリカバリーウェアを、価格、医療機器区分、独自技術、サイズ、特徴、店舗情報などの同じ基準で整理する静的な比較サイトです。

各ブランドの立ち位置を短く把握したうえで、比較表と選び方の基準から自分に合う商品を検討できる構成にしています。本サイトは各ブランドの公式サイトではなく、商品の販売も行いません。

## 掲載情報

- 掲載内容は各ブランドの公式商品ページ、技術紹介ページ、店舗一覧をもとに確認しています。
- 価格や商品仕様には確認日を記載し、購入前に公式サイトで最新情報を確認するよう案内しています。
- 医療機器に関する表現は、各社が案内する一般医療機器の範囲を超えないようにしています。
- 現在、広告、スポンサー記事、アフィリエイトリンク、問い合わせフォーム、独自のアクセス解析は設置していません。
- 今後、広告やアクセス解析などを導入する場合は、必要な表示やプライバシー情報を追加します。

## AIの利用

本サイトは、文章の整理、UI設計、実装、コード検証、ヒーロー画像の生成にAI支援を利用して制作しています。

AIが生成した内容をそのまま掲載するのではなく、比較情報と外部リンクは各ブランドの公式サイトを参照して確認・編集しています。掲載情報の最終的な判断や購入判断は、各ブランドの公式情報を優先してください。

## 技術構成

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React
- Vercel

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## 検証

```bash
npm run lint
npm run build
```

## 主なファイル

- `src/app/page.tsx`: ページ本体
- `src/data/brands.ts`: 比較ブランドのデータ
- `src/app/globals.css`: グローバルスタイル
- `public/recovery-hero-generated-v2.png`: AI生成のヒーロー画像
